# 5. Noms, abonnements et limites

Le FnameResolver valide les noms ENS Farcaster émis hors chaîne, tandis que le TierRegistry traite les paiements d’abonnement. Le protocole combine donc identité, clés, stockage et services optionnels dans des contrats spécialisés plutôt que dans un monolithe.

Les limites sont importantes : l’état dépend des permissions, des gateways, des opérateurs de récupération et de l’indexation des événements. Les déploiements varient selon le réseau et les versions de contrats.

Périmètre : ce parcours décrit les contrats, interfaces, README et dossiers docs visibles dans le dépôt. Aucune installation, compilation, test ou déploiement n’a été effectué ; les tests du dépôt restent la référence pour une vérification ultérieure.
